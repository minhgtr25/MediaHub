No project/invoice/backfill/provider calls |
| 024: order-origin production in existing projects/milestones | Medium: legacy status/RPC/direct Admin writes bypass commercial gates or transfer scope | Nullable unique order link and separate production_status; old rows remain NULL; legacy status DRAFT is not execution state. Seven rollback suites plus HTTP/build checks before apply; no invoice/financial backfill or creator booking |
| Future request/order separation | High: legacy project does not prove quote/contract/payment acceptance | Nullable links, explicit legacy origin, no guessed signatures/receipts or wholesale status conversion |
| Future payment/invoice reconciliation | High: historical receipt provenance varies | Preserve receipts, idempotent transaction ledger, explicit reconciliation/audit; never overwrite payment amounts from frontend |
| Future staff assignment | Medium: widening roles without assignment leaks customer data | Role + resource assignment at API and RPC/RLS, private queue summary, transfer revokes previous access |
